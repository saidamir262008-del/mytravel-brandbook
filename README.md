# myTravel — брендбук и выбор логотипа

Публичная версия материалов по бренду **myTravel** — travel-суперприложения
для Узбекистана (авиабилеты, отели, круизы, туры, аренда авто и квартир,
трансфер, виза, страховка, экскурсии, автобус/ЖД, карго, концерты).

## Что здесь

| Страница | Что это |
|---|---|
| [Выбор логотипа](https://saidamir262008-del.github.io/mytravel-brandbook/) | 24 варианта знака из восьми направлений, каждый в 15 цветовых схемах. Главная страница |
| [Брендбук](https://saidamir262008-del.github.io/mytravel-brandbook/brand/brandbook.html) | Цвет, типографика, иконки, применение, доступность. Один самодостаточный файл |
| [Компоненты интерфейса](https://saidamir262008-del.github.io/mytravel-brandbook/brand/components/ui-kit.html) | Живые компоненты: поиск, карточки результата, форма пассажира, оплата, ваучер под печать |

## Как выбирать логотип

1. Сначала форма, потом цвет — это два разных решения.
2. Смотрите на средний ряд каждой карточки: логотип в 34 и 20 пикселей. Это его
   настоящая жизнь — шапка приложения, вкладка браузера, аватарка.
3. Нажмите «Скопировать ID» под понравившимся вариантом и пришлите код,
   например `plaque/plaque-01`. Если форма нравится, а цвет нет — пришлите ID
   и название цвета.

## Структура репозитория

```
index.html      лист выбора логотипа (самодостаточный, шрифты внутри)
brand/          брендбук: токены, логотип, иконки, компоненты, документы
logo-lab/       исходные SVG всех вариантов знака + notes.md по каждому направлению
```

## Техническое

- Все страницы самодостаточные: шрифты вшиты как base64, внешних запросов нет.
- Контуры букв в логотипах переведены в кривые — файлы одинаково отрисуются
  на машине без установленных шрифтов.
- Шрифты Alegreya, IBM Plex Sans и IBM Plex Mono — под SIL Open Font License 1.1.
- Логотипы, иконки, тексты и токены — собственность myTravel.

Все имена, номера заказов, рейсы и телефоны в примерах вымышленные.
