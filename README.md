# myTravel — брендбук и выбор логотипа

Публичная версия материалов по бренду **myTravel** — travel-суперприложения
для Узбекистана (авиабилеты, отели, круизы, туры, аренда авто и квартир,
трансфер, виза, страховка, экскурсии, автобус/ЖД, карго, концерты).

## Логотип

Слово ведёт композицию, под ним лежит взлётная полоса, и за последней буквой
она отрывается от земли. Единица системы — капитальная высота, равная 100:
полоса на 48 ниже базовой линии, толщина 23, отрыв — плюс 182 по горизонтали
и минус 100 по вертикали. Словесный знак набран Schibsted Grotesk 700
с трекингом −14 и переведён в кривые.

Восемь компоновок: основная, компактная, вертикальная, в плашке, только приём,
только слово, с дескриптором и микро — для высоты блока 18–24 px.
У каждой четыре версии: основная, выворотка, монохром через `currentColor`
и версия с CSS-переменными для любого цвета.

## Структура репозитория

```
index.html      логотип: компоновки, цвета, иконки, анимация, правила
choose.html     архив: 24 варианта, из которых выбирали
brand/          брендбук: токены, логотип, иконки, компоненты, документы
logo-lab/       исходные SVG всех вариантов знака + notes.md по каждому направлению
```

## Техническое

- Все страницы самодостаточные: шрифты вшиты как base64, внешних запросов нет.
- Контуры букв в логотипах переведены в кривые — файлы одинаково отрисуются
  на машине без установленных шрифтов.
- Шрифты Alegreya, IBM Plex Sans и IBM Plex Mono — под SIL Open Font License 1.1.
- Логотипы, иконки, тексты и токены — собственность myTravel.

Все имена, номера заказов, рейсы и телефоны в примерах вымышленные.
