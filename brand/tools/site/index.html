Сборка сайта

Скрипты, которые собирают этот сайт: листинги папок, карту материалов и HTML-версии документов. Запускаются одной командой ./build-site.sh из корня проекта — она же проверяет все ссылки и не даёт выложить сайт с битыми.

Порядок

1. брендбук и страница логотипа
2. документы из markdown, листинги папок
3. копирование материалов в _site
4. карта материалов
5. проверка всех ссылок

Почему листинги собираются в исходниках. Копия сайта пересоздаётся при каждой сборке. Если генерировать страницы прямо в ней, они будут затёрты — на этом уже спотыкались.
