# Генератор логотипа

Логотип myTravel не нарисован в редакторе, а **вычисляется**: все компоновки
выводятся из одних и тех же величин. Поэтому его можно пересобрать, изменить
пропорции или добавить новое положение, ничего не перерисовывая руками.

## Величины системы

Единица — капитальная высота слова, равная 100.

| Что | Значение |
|---|---|
| Слово | Schibsted Grotesk 700, трекинг −14, базовая линия y = 0 |
| Полоса | лежит на 48 ниже базовой линии, толщина 23, скруглённые концы |
| Отрыв | кривая: +182 по горизонтали, −100 по вертикали |
| Самолёт | сидит на конце кривой, угол совпадает с касательной |

Эти числа сняты с утверждённого варианта: пересборка совпадает с ним
с расхождением 0.0000 — проверяется скриптом при каждом запуске.

## Файлы

| Файл | Что делает |
|---|---|
| `logo_system.py` | Сама система: слово, полоса, самолёт и восемь компоновок |
| `pathbbox.py` | Габариты SVG-путей без браузера — из них считается viewBox |
| `glyphs.py` | Доступ к отдельным глифам шрифта, чтобы резать и подменять буквы |
| `emit.py` | Выгружает комплект SVG в `brand/logo/` |
| `guide.py` | Собирает страницу-руководство `_logo.html` |
| `raster.py` | Растр из SVG через headless Chrome |
| `pack.py` | Собирает архив для пересылки: SVG, PNG, анимации, инструкция |
| `SchibstedGrotesk.ttf` | Шрифт словесного знака, SIL Open Font License 1.1 |
| `IBMPlexSans.ttf` | Шрифт дескриптора, SIL Open Font License 1.1 |

## Как запустить

Нужен Python 3 и `fonttools`:

```bash
python3 -m venv venv
./venv/bin/pip install fonttools brotli
```

Дальше из этой папки:

```bash
./venv/bin/python emit.py    # пересобрать все SVG в brand/logo/
./venv/bin/python guide.py   # пересобрать страницу-руководство
./venv/bin/python pack.py    # собрать архив для пересылки (нужен Chrome для PNG)
```

## Если нужно поменять логотип

- **Другой цвет** — на странице руководства уже 15 схем; для файлов правьте
  `ANOR` и `TUT` в `logo_system.py` или берите версии `-var` с CSS-переменными.
- **Новая компоновка** — добавьте функцию `lay_<имя>` в `logo_system.py`
  и строку в список `LAYOUTS` в `emit.py`. Габарит считать не нужно:
  `pathbbox` посчитает и выставит viewBox сам.
- **Другой шрифт** — поменяйте `FACE` в `logo_system.py` и положите файл рядом.
  Проверьте, что в нём есть все нужные глифы, прежде чем менять.

## Грабли, на которые уже наступали

- **viewBox с отрицательным началом координат.** Chrome неверно инстанцирует
  такой `<symbol>` через `<use>`: логотип уезжает и обрезается. Поэтому `svg()`
  приводит начало к (0, 0) — не убирайте это.
- **Рисунок за пределами viewBox.** Раньше габарит задавался на глаз, и часть
  логотипов молча обрезалась. Теперь он считается по фактическим точкам путей.
- **Полоса в мелком размере.** Ниже 24 px тонкая линия и мелкий самолёт
  схлопываются. Для 18–24 px есть компоновка `micro`, для иконок — жирный
  вариант приёма (`stroke=34`, `plane_scale=1.45`).
