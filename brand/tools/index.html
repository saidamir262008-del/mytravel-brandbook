brand/tools — три скрипта пересборки

Скрипты нужны, только если вы поменяли токены, логотип, иконки или шрифты. Обычная работа с брендбуком их не требует: все результаты уже лежат в репозитории.

Запускать из корня папки brand/, например python3 tools/build-brandbook.py.

Порядок важен. Сначала build-brandbook.py, потом build-fonts.py: второй ищет маркеры шрифтов в уже пересобранном файле. Оба идемпотентны — гонять можно сколько угодно раз.

Сборка сайта. Листинги папок, карта материалов и HTML-версии документов собираются скриптами из tools/site/. Всё вместе запускается одной командой ./build-site.sh из корня проекта — она же проверяет ссылки.

Логотип пересобирается отдельно. Он не рисуется руками, а вычисляется: все компоновки выводятся из капитальной высоты слова. Генератор и оба шрифта лежат в tools/logo/ — там же README с величинами системы, инструкцией запуска и списком граблей.

Страница собрана скриптом build-listings.py. Правьте материалы в папке и запускайте его заново — список пересоберётся. На главную брендбука.
