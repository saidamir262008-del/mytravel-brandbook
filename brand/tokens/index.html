Брендбук myTravel / brand / tokens

brand/tokens — цвет, шрифт, отступы

Два файла с одним и тем же содержимым в разных форматах: CSS для разработчика и JSON для дизайнера. Всё, что в продукте имеет цвет, размер или отступ, берётся отсюда.

Источник правды — tokens.css. JSON собирается по нему; при расхождении верить CSS.

Правило про красный. Гранат — цвет бренда и главного действия, поэтому ошибка никогда не обозначается одним красным: всегда красный плюс иконка плюс текст. Статус «отменено» — нейтральный, иначе он спорит с кнопкой «Оплатить».
