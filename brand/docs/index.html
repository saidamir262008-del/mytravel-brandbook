brand/docs — правила, тон и доступность

Три текстовых документа брендбука. Каждый лежит в двух видах: готовая HTML-страница для чтения и Markdown-исходник для правки.

Если сомневаетесь, с чего начать — начните с правил использования: они короче остальных и отвечают на большинство вопросов.

HTML и Markdown — один и тот же текст. HTML удобно читать в браузере, Markdown удобно смотреть в diff и цитировать в задачах. Правится Markdown, HTML собирается по нему.

Страница собрана скриптом build-listings.py. Правьте материалы в папке и запускайте его заново — список пересоберётся. На главную брендбука.
